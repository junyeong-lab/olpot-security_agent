# 올폿 전체 화면 복원 + 직원용 요약

직원용 요약 카드는 기존 대시보드에 **추가**합니다. 기존 올폿 화면의 로그인·기기·세션·업무 앱·보안 기록·학습 표시·연결 및 진단 기능을 숨기거나 삭제하지 않습니다.

## 기본 화면
- 기존 보호 현황과 모든 학습·진단 카드 표시
- PC 상태: 백신/방화벽/회사 연결/저장 공간 요약 4개를 우선 표시하며, 같은 PC 상태 카드에서 **「상세 PC 정보 보기」를 눌러** CPU·메모리·네트워크·Windows 이벤트·VPN·백신·로그인 등 기존 상세 항목 전체를 펼쳐 볼 수 있음. 기본은 접힘.
- 기존 업무 앱, 보안 기록 탭 유지
- 회사 서버 미연결인 `local-pc` 실행에서는 기존 앱의 연결 상태 확인 로직이 AI 연결 카드 일부를 숨길 수 있으나, 보안 서버 연결 성공으로 오인하지 않습니다. 이 상태는 기존 구현에 따른 것입니다.

## 준수
- student/extension.mjs, 수집 로직, 서버 API, main 브랜치, 기존 개발 브랜치 보존
- 관리자용 별도 앱은 **이 전체 화면의 검증 이후** 복제 작업으로 진행
- 백신 등록 정보, 방화벽 켜짐 또는 로컬 VPN 프로필 개수만으로 회사 접근 허용이나 완전한 보안 상태를 판정하지 않습니다
