# 올폿 직원용 화면 1차 정리

## 목적

직원이 일상적으로 사용하는 보안 Agent의 첫 화면을 단순화합니다. 교육용 카드, 이벤트 ID, 오류 발생 횟수 등은 직원 기본 화면에서 치우고 필요할 때만 기술 진단을 열 수 있습니다.

## 직원 기본 화면

- 내 PC 보안 상태: 백신 등록 정보(실제 실시간 보호와 구분), Windows 방화벽 설정, 회사 연결 확인 안내, 디스크 여유 공간
- 업무 앱: 기존 접속 요청·판정 흐름 유지, 미연결 상태는 허용으로 표시하지 않음
- 보안 기록: 사용자가 확인할 수 있는 기존 기록만 유지
- 상세 PC 진단: CPU·메모리·디스크·네트워크·VPN·Windows 이벤트·로그인 기록 등 기존 10개 카드를 접기/펼치기로 보존

## 개발·실습 기능의 보존

왼쪽 메뉴 '개발자 옵션 > 진단·실습 화면 보기'는 기존 학습·진단 카드를 화면에 다시 나타내는 **시각적 전환**에 불과합니다. 관리자 인증/권한 분리가 아니므로 실제 기업 배포 시에는 서버 측 역할 기반 권한 검증과 별도의 관리자 앱이 필요합니다.

기존 student/extension.mjs, 서버, 로그·AI 조치 로직, API 및 main 브랜치는 변경하지 않습니다. 실제 업무 접근 허용 여부는 이 첫 화면만으로 판정하지 않습니다.

## 다음 단계 (이번 커밋 범위 밖)

직원용 화면과 기존 ZTNA 접속 절차를 실기기에서 재검증한 다음 **이 버전을 기준으로 별도 관리자용 브랜치/앱을 복제**합니다. 서버 연동·권한 모델이 정해지기 전에는 직원 UI에 관리자 조치 버튼을 추가하지 않습니다.

## 검증

on-client 폴더에서 다음을 수행합니다.

- 실제 브라우저에서 직원 화면/개발자 옵션/상세 진단 토글과 업무 앱 탭을 확인합니다.
