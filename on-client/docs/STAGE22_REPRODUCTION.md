## 2. 폴더·설치·실행·관찰 기록 (2026-10-28)

원본: Windows Workbench의 olpot-security_agent 폴더. 기존 Git SHA 및 학생 코드·설명서가 보존된 것을 사용자가 PowerShell에서 확인했다. 기존 설명서 .bak, .premerge.bak 파일은 보존되었고, 22단계 준비 중 추가 백업도 생성했다. 백업을 Git 제출물에 포함하지 않는다.

독립 환경: 사용자 홈 아래 별도 신규 폴더에 GitHub를 --no-checkout으로 복제하고, 기준 SHA로 detached HEAD 체크아웃한 뒤 실행했다. 이 임시 폴더는 검증 후 사용자의 요청으로 삭제했다. **현재 유지 중인 재현 환경이 아니다.**

절차 및 결과:

1. 원본의 Git HEAD가 기준 40자리 SHA임을 확인. 추적 중인 코드 변경이 없고 백업 2개가 untracked로 존재함을 확인(학생 실행 출력).
2. 독립 폴더가 존재하지 않음을 Test-Path로 확인한 후 git clone --no-checkout --branch main --single-branch을 수행. 해당 SHA에 git switch --detach 수행. HEAD 메시지 확인(학생 실행 출력).
3. node -v: v24.21.0. npm.cmd --prefix <새 폴더의 on-client> run check: exit 오류 없이 node --check student/extension.mjs 완료(학생 실행 출력, **문법만 확인**).
4. 별도 인스턴스를 기존 서버와 동시에 실행하기 위해 -Port 5190으로 시작. 브라우저 127.0.0.1:5190의 기본 화면과 '보호 현황' 표시를 사용자가 확인함. 5190 포트는 분리 실행을 위한 선택값이며 필수 제출 포트가 아니다.
5. 새 인스턴스의 PowerShell에서 Ctrl+C로 종료하고 동일 폴더·포트에서 다시 실행. 사용자가 브라우저 화면의 정상 재표시까지 확인함.
6. 새 인스턴스의 계정·기기·세션에는 '연결 없음' 및 '기존 서버·에이전트의 연결을 확인할 수 없습니다'가 표시됨. 기존 5189 인스턴스에서도 동일하게 '연결 없음'. **실제 SDP 데이터 조회 성공이 아니다.**
7. 임시 5190 서버가 LISTEN 상태가 아님을 확인하고, 복제 폴더 삭제 및 Test-Path False 확인(학생 실행 출력).
8. 기존 5189 서버에서 HTTP 200 확인 및 ALEPH 계정·AI 연결 완료. 사용자가 AI 연결 점검 결과 audienceAuthorization verified, 응답 모델 1개, 점검시각 2026-10-28T01:45:01.636Z (KST 10:45:01)을 직접 제공. **이는 5189의 점검이며 5190 재현 결과가 아니다.**

정확한 개별 시험 시작/종료 시각은 별도 기록하지 않았다. 근거의 출처는 대화 중 사용자가 제공한 PowerShell 출력 및 직접 화면 확인 보고이며, 서버 실행 로그·스크린샷 전체가 이 Git 커밋에 포함된 것은 아니다.

## 4. 이동 가능한 구성과 설정

Git 저장소 최상위 폴더는 on-client의 상위 폴더이다. 앱 실행 위치는 on-client이다. 지원 Node.js 22~24 중 사용자 PC 실제 버전 v24.21.0을 기록한다.

기본 재현 실행 명령(Windows PowerShell, 앱 폴더 기준):

~~~powershell
npm.cmd run check
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1 -Port 5190
~~~

브라우저 http://127.0.0.1:5190/ 확인 후 실행 중인 PowerShell에서 Ctrl+C로 종료하고 같은 명령으로 재실행한다. 원본 서버가 사용 중이지 않으면 기본 5189 포트를 사용해도 된다. 별도 디렉터리에 복제할 때는 정확한 40자리 제출 SHA를 고정한다.

README 및 .env.example은 비밀 없는 실행·설정 견본이고, 실제 인증서·토큰·개인키·비공개 호스트 설정을 Git에 넣지 않는다. 기본 학생 어댑터는 disconnected이다. 실제 SDP 연결은 운영자가 발급한 개인 설정과 자격이 필요하며 이번 검증에서 제공되지 않았다. ALEPH AI 연결은 SDP 연결과 다르다.

## 6. 최종 릴리스 판정 경계와 남은 작업

- 상태: **검증 중**. 22단계 원문 검토 통과 여부 미확인. 운영 인증·v1.0 자동 확정 아님.
- 아직 구현·검증되지 않은 운영 연결: 실제 SDP 접근 제어 및 조치 효과 관측, 승인된 실집행, 외부 OSV 조회 결과, AI 사건 설명 성공.
- 21단계 기준 e97ba74... 재현과 22단계 첫 문서 후보 67ef2ee... 재현, 그리고 **이번 보완 기록을 포함한 신규 최종 SHA 재현**은 서로 다르다.
- 이 문서가 포함된 커밋을 생성한 뒤, 같은 커밋을 새 폴더에 받아 직접 재현해야 최종 소스 기준의 관찰 결과라고 기록할 수 있다. 그 전까지는 최종 커밋 재현을 미확인으로 둔다.
- 공식 22단계 제출은 저장소 URL과 실제 최종 40자리 SHA를 입력하고 서버 AI 원문 검토 판정을 확인한다. 서버의 원문 검토를 코드 실행·시연 성공 인증이라고 표현하지 않는다.
