## 1. 무엇을 준비하나요?

- **Windows + PowerShell**: 일반 사용자 권한에서 실행합니다. 관리자 권한으로 실행할 필요가 없습니다.
- **Node.js 22~24**: 수업 기준은 **24.19.0**이며, 같은 지원 범위인 다른 패치 버전도 실행 도구가 허용합니다. PowerShell에 `node --version`을 입력해 확인합니다. Node가 없거나 범위를 벗어난 경우에만 공식 Node.js 배포 경로를 통해 알맞은 버전을 준비한 뒤 PowerShell을 다시 엽니다.
- **추가 npm 설치는 필요하지 않습니다.** 이 시작 틀의 `package.json`에는 외부 npm 의존성이 없습니다. `npm install` 또는 포장 명령을 실행하지 않습니다.
- **기존 프로젝트 위치**(이 PC의 확인된 사례):
  `C:\Users\User\AppData\Local\ALEPH\Workbench\projects\olpot-security_agent\on-client`
- Windows 계정·PC에 따라 경로가 다를 수 있습니다. **다른 사람의 PC에는 이 경로의 프로젝트가 자동으로 존재하지 않습니다.** 이미 가지고 있는 `on-client` 폴더를 직접 확인하세요.

## 2. 기존 앱 폴더를 여세요

파일 탐색기에서 **기존** `olpot-security_agent\on-client` 폴더를 엽니다. `tools\start-alekov.ps1`과 `student\extension.mjs` 파일이 있는지 확인합니다.

파일 탐색기의 주소 표시줄에 `powershell`을 입력한 후 Enter를 눌러 해당 폴더에서 PowerShell을 열 수 있습니다. 또는 프로젝트가 위 경로에 있는 PC에서는 아래의 **전체 경로 명령**을 어느 위치에서든 실행할 수 있습니다.

폴더나 파일이 없다면 새 프로젝트를 만들거나 제공 파일을 덮어쓰지 말고, 기존 경로를 다시 확인하세요.

## 3. 앱을 실행하세요

기존 폴더의 PowerShell에서 실행:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1
```

위에서 확인한 Workbench 경로를 사용하는 PC라면 어디서든 실행할 수 있는 동일한 명령:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\ALEPH\Workbench\projects\olpot-security_agent\on-client\tools\start-alekov.ps1"
```

- 이미 **5189 서버가 실행 중이라면 중복 실행하지 말고 기존 브라우저 화면을 사용**합니다.
- 실행 도구에서 서버 주소를 안내하면 브라우저로 `http://127.0.0.1:5189/`를 엽니다.
- PowerShell 창을 계속 열어 둡니다. 서버 실행 성공은 **로컬 앱의 실행 성공**일 뿐, AI·SDP 연결 성공이나 침해 탐지 결과가 아닙니다.
- `-ExecutionPolicy Bypass` 옵션은 해당 프로세스 실행에만 적용하며 시스템 전체 실행 정책을 변경하는 명령이 아닙니다.

## 4. 첫 화면과 세 가지 핵심 기능을 확인하세요

브라우저 `http://127.0.0.1:5189/`에서 **보호 현황**을 엽니다. 4일차 수정본이 적용된 기존 폴더라면 학생 영역의 **olpot · 내 PC 관제**를 확인합니다.

1. **맨 위 상태 카드 4개**: 네트워크 구성(개), Windows 방화벽(Domain·Private·Public), 최근 24시간 System·Application 기록(경고·오류 **건**), SDP 연결 상태.
2. **PC 실측 변화 비교·추이**: 제공 `내 PC 상태`의 CPU(%), 메모리(%), 디스크 여유(GB) 조회와 중복하여 현재값을 만들지 않고, 학생 영역에서는 서로 다른 시각의 실제 측정 결과 **2회 이상**으로 변화량(%p·GB·건)을 설명합니다.
3. **기록·출처·다음 행동**: 각 항목의 측정 시각과 단위, 실제 조회 출처 및 실패 사유를 확인합니다.

**다시 조회** 버튼은 마우스로 클릭하거나 키보드 `Tab`으로 선택한 뒤 `Enter` 또는 `Space`로 실행합니다. 조회 중에는 `조회 중…`이 표시되고 중복 조회를 막습니다. 조회 성공 시 측정 시각을 기록하고, 2회 이상 성공해야 추이가 나옵니다. **추이 이력은 페이지 메모리에만 있어 새로고침하면 초기화됩니다.**

**근거를 구분합니다.**
- **실측**: 이 PC의 읽기 전용 `/api/pc/status`에서 확인한 값·단위·측정 시각을 함께 보여 줍니다.
- **예시·설명용**: 실행 예제나 과제 샘플 화면의 수치는 이 PC의 조회 결과가 **아닙니다**. 현재값으로 쓰지 않습니다.
- **확인 불가**: 값이 없거나 읽을 권한·지원·응답이 없으면 실제 원인과 다음 행동을 보입니다. 임의로 `0`, `정상`, `안전`으로 바꾸지 않습니다.
- **SDP 미연결**: PC 측정 성공과는 별개입니다. 원천 연결·실제 보안 조치 성공으로 오해하지 않습니다.
- **Windows 경고·오류**: 시스템 기록의 건수일 뿐 **침해나 공격 탐지 결과가 아닙니다.**
